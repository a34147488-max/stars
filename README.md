# Stars — кликер звёзд и Telegram-бот

Проект содержит веб-кликер и Telegram-бота. Баланс, профиль и переводы хранятся в PostgreSQL, чтобы бот и приложение использовали один счёт.

## Запуск и публикация

Нужен Node.js 18+ и PostgreSQL.

1. Создай бота через [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Разверни репозиторий на Railway как Node.js-приложение. Команда запуска: `npm start`.
3. Добавь сервис PostgreSQL и передай приложению переменные окружения:
   - `BOT_TOKEN` — токен от BotFather.
   - `DATABASE_URL` — строка подключения PostgreSQL от Railway.
   - `APP_URL` — публичный HTTPS-адрес этого приложения, например `https://твой-домен.up.railway.app`.
4. После успешного запуска открой бота и нажми `/start`. Кнопка «Открыть кликер» открывает Telegram Mini App.
5. В BotFather можно настроить описание и команды бота, например `start - открыть Stars`, `balance - баланс`, `transfer - перевод звёзд`.

## Возможности

- Клик в приложении и боте начисляет по `0.0001` звезды.
- Общий серверный баланс и накопленная сумма в PostgreSQL.
- Изменение имени и выбор эмодзи-аватара в приложении.
- Персональная реферальная ссылка вида `https://t.me/ИМЯ_БОТА?start=ref_ID`.
- Перевод звёзд по Telegram username: `/transfer @username 1.5` или через форму в приложении.
- Просмотр баланса командой `/balance`.
- Зимнее оформление, снег, гирлянда и музыкальная кнопка.

## Важно

- Баланс синхронизируется, когда приложение открыто через кнопку Telegram-бота. Обычное открытие страницы вне Telegram не имеет подтверждённого Telegram-профиля.
- Получатель перевода должен хотя бы раз нажать `/start` и иметь Telegram username.
- Реферальный ID закрепляется только при первой регистрации нового игрока. Сама ссылка создаётся, но бонус за приглашение в текущей версии не начисляется.
- Ранее накопленный баланс из старого `localStorage` браузера автоматически в PostgreSQL не переносится.
- Для безопасности не публикуй `BOT_TOKEN` и `DATABASE_URL` в файлах репозитория.
