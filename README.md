# Stars — кликер звёзд

Браузерная игра-кликер с большой SVG-звездой, 10 улучшениями силы клика и 5 видами автокликера. Прогресс сохраняется в localStorage браузера.

## Запуск

Откройте `index.html` в браузере или подключите репозиторий к хостингу статических сайтов (например, GitHub Pages).

- Базовая награда за клик: `+0.0001` звезды.
- 10 разных улучшений силы клика.
- 5 видов автокликера.
- Автоматическое сохранение прогресса на устройстве.
